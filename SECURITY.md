# Security Policy

## Reporting a vulnerability

Please do not open a public issue containing credentials, private configuration, personal data, customer information, or exploit details that would put users at immediate risk.

Until a dedicated private reporting channel is configured, open a minimal public issue stating that you have a security report **without including the sensitive details**. A maintainer can then arrange an appropriate private handoff.

## Scope and claims

PandaCheck is an early configuration scanner. A clean scan is not a security certification, penetration test, or guarantee of safety.

## Test data

Repository fixtures must be synthetic. Real user configurations, credentials, private archives, and confidential customer material must not be committed as examples or tests.
